# Joshua Crump

Server Engineer with 10+ years in Windows infrastructure - Active Directory, VMware, Microsoft 365, security operations, and enterprise systems administration.

Outside of work I run **CrumpNet**, a homelab built around real infrastructure work. The goal isn't to run every possible tool, but to build a useful, maintainable environment for learning, testing, and documentation outside of production:

- **Identity** - Active Directory, DNS, DHCP, and PKI
- **Visibility** - Monitoring, alerting, and security event collection
- **Services** - Docker workloads, Linux administration, and backup
- **Networking** - VLANs, segmentation, and firewall management
- **Automation** - PowerShell scripting and configuration management

## Writing

Technical write-ups, design decisions, and lessons learned are at **[crump.net](https://crump.net)** - written to be useful during an outage, to share with a colleague, or to revisit years later without reverse-engineering past decisions.
